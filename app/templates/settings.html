How to enable real SMS

Set environment variables (Railway / local):

ALERT_PHONE=03107319742
ALERT_EMAIL=sasolarandelectricco@gmail.com
# Twilio
TWILIO_ACCOUNT_SID=ACxxxxxxxx
TWILIO_AUTH_TOKEN=your_token
TWILIO_FROM_NUMBER=+1234567890
# Or local SMS API
SMS_API_URL=https://api.example.com/send?key={key}&to={phone}&message={message}
SMS_API_KEY=your_key
# Email (Gmail)
SMTP_HOST=smtp.gmail.com
SMTP_USER=your@gmail.com
SMTP_PASS=app_password

Without API keys, alerts go to logs/alerts.log (safe for testing).
